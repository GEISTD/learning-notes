技巧：快捷路径

危险：rm 命令
永远不要执行 rm -rf / 或 rm -rf ~。
建议用 alias rm='rm -i' 加确认提示。删除前先 ls 确认路径。

权限数字速查
# 权限格式：所有者 | 组 | 其他 # r=4(读) w=2(写) x=1(执行) 777 = rwxrwxrwx # 全部权限（危险） 755 = rwxr-xr-x # 所有者全权限，其他人只读+执行 644 = rw-r--r-- # 所有者读写，其他人只读 600 = rw------- # 仅所有者读写 +x = 给所有用户加执行权限 # 用于脚本
sudo vs su 的区别
命令需要的密码作用
sudo cmd自己的密码以root权限执行单条命令
su -root密码切换到root用户环境
sudo -i自己的密码用sudo切到root环境（推荐）
sudo su -自己的密码等价于 sudo -i

管道与重定向

核心概念
符号说明示例
| 管道：前一个命令的输出作为后一个的输入 ps aux | grep python
> 输出重定向（覆盖） echo "hello" > file.txt
>> 输出重定向（追加） echo "world" >> file.txt
2> 错误输出重定向 cmd 2> error.log
&> 正确和错误都重定向 cmd &> all.log
< 输入重定向 sort < list.txt
<< Here Document（多行输入） cat << EOF ... EOF
&& 逻辑与（前一个成功才执行下一个） make && make install
|| 逻辑或（前一个失败才执行下一个） cmd || echo "失败"
; 顺序执行（不管成功失败） cmd1 ; cmd2
管道经典组合
# 1. 查找正在运行的进程 ps aux | grep python # 2. 统计某种文件数量 find . -name "*.py" | wc -l # 3. 查看占用内存最多的5个进程 ps aux | sort -rnk4 | head -5 # 4. 找出最大的文件 du -ah ~ | sort -rh | head -10 # 5. 批量修改文件权限 find . -name "*.sh" | xargs chmod +x # 6. 在日志中统计错误出现次数 grep -c "ERROR" app.log # 7. 替换文件中的字符串 sed -i 's/old_name/new_name/g' *.py

面试高频问题速答

面试专用
问题参考回答
怎么查看端口被谁占用了？ ss -tlnp | grep 端口号 或 lsof -i:端口号
怎么查看系统资源？ top/htop(进程) free -h(内存) df -h(磁盘) uptime(负载)
怎么查看实时日志？ tail -f logfile 配合 grep 过滤关键词
怎么查找7天内修改过的文件？ find . -mtime -7 -type f
怎么杀掉卡住的进程？ 先 ps aux | grep 名称 找PID，再 kill -9 PID
软链接和硬链接的区别？ 软链接(ln -s)是快捷方式，可以跨文件系统，删除源文件后失效；硬链接(ln)是同一个inode，不能跨文件系统，删除源文件后仍可用
怎么设置开机自启服务？ sudo systemctl enable 服务名（基于systemd）
怎么在文件中搜索并替换文本？ sed -i 's/旧文本/新文本/g' 文件名
怎么查看一个命令的详细用法？ man 命令 或 命令 --help
环境变量怎么设置？ export VAR=value(临时) / 写入 ~/.bashrc 或 ~/.zshrc(永久)
怎么在后台运行程序？ nohup command & 退出终端不中断，输出默认到 nohup.out
chmod 755 是什么意思？ 所有者=rwx(7)，组=r-x(5)，其他=r-x(5)。常用于脚本和目录
怎么查看当前网络IP？ ip addr(内网) / curl ifconfig.me(公网)
