## 1. 复杂度分析

### 1.1 时间与空间复杂度

- **时间复杂度**描述输入规模 `n` 增长时，操作次数如何增长；它不是某台机器上的实际秒数。
- **空间复杂度**描述算法额外使用的空间。通常区分总空间与辅助空间；递归调用栈也占用空间。
- 常见分析口径包括最坏情况、平均情况和摊还复杂度。题目未特别说明时，通常先报告最坏情况。

### 1.2 渐进记号

- `O(g(n))`：渐进上界，常用于描述最坏增长速度。
- `Ω(g(n))`：渐进下界。
- `Θ(g(n))`：渐进紧确界，表示上下界同阶。

忽略常数与低阶项：`3n² + 10n + 7 = Θ(n²)`。复杂度不是精确运行时间，也不能仅凭 `O` 判断两个实际程序的快慢。

### 1.3 常见增长级别

由慢到快大致为：

`O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)`

例子：

- 循环 `i *= 2`：`O(log n)`。
- 两层各遍历 `n` 次的嵌套循环：`O(n²)`。
- 对半划分并在线性时间合并：`O(n log n)`。
- 枚举所有子集：`O(2ⁿ)`。

### 1.4 循环和递归的估算

连续执行的代码段取复杂度之和的主导项；嵌套执行通常相乘。循环次数若随变量变化，应写出求和式再化简。例如：

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2} = \Theta(n^2)$$

递归常用递推式分析。主定理适用于 `T(n)=aT(n/b)+f(n)`（通常要求规模均匀缩小）：

$$T(n)=\begin{cases}
\Theta(n^{\log_b a}) & f(n)=O(n^{\log_b a-\epsilon})\\
\Theta(n^{\log_b a}\log n) & f(n)=\Theta(n^{\log_b a}\log^k n)\\
\Theta(f(n)) & f(n)=\Omega(n^{\log_b a+\epsilon})\text{ 且满足正则条件}
\end{cases}$$

例如归并排序 `T(n)=2T(n/2)+Θ(n)=Θ(n log n)`；二分查找 `T(n)=T(n/2)+Θ(1)=Θ(log n)`。

### 1.5 摊还分析

动态数组追加一次偶尔需要扩容并复制元素，单次最坏是 `O(n)`；若容量按倍数增长，连续追加 `n` 次的总搬移仍为 `O(n)`，所以每次追加的摊还复杂度为 `O(1)`。不要把“偶尔昂贵”误判成每次都昂贵。

## 2. 数组、链表、栈、队列与字符串

### 2.1 数组与动态数组

数组元素连续存储，可通过下标在 `O(1)` 时间访问。静态数组容量固定；动态数组通过预留容量支持增长。

| 操作 | 典型复杂度 |
|---|---:|
| 下标访问 / 更新 | `O(1)` |
| 未排序数组查找 | `O(n)` |
| 尾部追加（摊还） | `O(1)` |
| 中间插入 / 删除 | `O(n)` |

适合随机访问、批量遍历和缓存友好场景。频繁在头部或中间插入时需要移动后续元素。

### 2.2 链表

链表由节点和指针组成。单链表节点只指向后继；双链表还指向前驱。若已经持有目标位置的节点，插入、删除可为 `O(1)`；若要先按值查找位置，则仍需 `O(n)`。

```python
class Node:
    def __init__(self, value, next_node=None):
        self.value = value
        self.next = next_node

def reverse(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev, cur = cur, nxt
    return prev
```

迭代反转链表：时间 `O(n)`，额外空间 `O(1)`。常见链表题还包括快慢指针找中点、检测环（Floyd 判圈）、合并有序链表和删除倒数第 `k` 个节点。

### 2.3 栈

栈遵循 **LIFO**（后进先出）。核心操作 `push`、`pop`、查看栈顶通常为 `O(1)`。典型用途：函数调用、括号匹配、表达式求值、单调栈、深度优先搜索。

括号匹配思路：左括号入栈；右括号必须匹配栈顶并弹出；最后栈必须为空。时间 `O(n)`，空间 `O(n)`。

**单调栈**维护栈内元素单调递增或递减，常用于“下一个更大/更小元素”、柱状图最大矩形。每个元素最多入栈、出栈一次，因此整体通常是 `O(n)`。

### 2.4 队列与双端队列

队列遵循 **FIFO**（先进先出），在尾部入队、头部出队。循环数组避免移动元素；双端队列支持两端插入和删除。Python 中可使用 `collections.deque`。

典型用途：广度优先搜索、任务调度、滑动窗口。滑动窗口最大值可用单调双端队列维护候选下标，使每个元素最多进出队一次，总体 `O(n)`。

### 2.5 字符串

字符串通常不可变；频繁拼接可能产生重复复制，宜收集片段后统一连接。常考问题包括：双指针回文判断、字符计数、模式匹配和子串查找。

KMP 用前缀函数（失败函数）记录模式串自身前后缀的最长相等长度，避免失配后从头比较。构造和匹配均为 `O(n+m)` 时间，额外空间 `O(m)`。注意区分“子序列”与“子串”：子序列允许跳过字符，子串必须连续。

## 3. 树与重要算法

### 3.1 基本概念与遍历

树是连通且无环的层次结构。根节点无父节点；叶节点无子节点。二叉树节点至多有两个孩子。高度常按边数或节点数定义，做题时应先确认约定。

二叉树遍历：

- 前序：根、左、右。
- 中序：左、根、右；对二叉搜索树会得到有序序列。
- 后序：左、右、根；常用于自底向上计算。
- 层序：按层访问，使用队列。

递归遍历的时间 `O(n)`，递归栈空间 `O(h)`（`h` 为树高）。退化成链时 `h=n`。

```python
def inorder(root):
    if root is None:
        return
    inorder(root.left)
    visit(root.value)
    inorder(root.right)
```

### 3.2 二叉搜索树（BST）

BST 满足左子树键值小于根、右子树键值大于根（重复键如何处理需明确）。查找、插入、删除复杂度为 `O(h)`：平衡时 `O(log n)`，退化时 `O(n)`。删除节点分三种：叶节点直接删；单孩子用孩子替代；双孩子用中序后继或前驱替换，再删除替代节点。

### 3.3 平衡树、堆与 Trie

- **AVL 树**：任一节点左右子树高度差绝对值至多为 1，通过旋转维持平衡；查找、插入、删除 `O(log n)`。
- **红黑树**：用颜色约束保证高度 `O(log n)`，更新时通过旋转和变色维护性质，常用于有序映射实现。
- **二叉堆**：完全二叉树，最大堆父节点不小于子节点，最小堆相反。查看堆顶 `O(1)`，插入和弹出 `O(log n)`，建堆 `O(n)`。堆不是完整有序结构。
- **Trie（前缀树）**：按字符路径存储字符串，查找长度为 `L` 的键通常为 `O(L)`；空间与所有键的字符总量相关，适用于前缀检索。

### 3.4 常见树算法

- 最大深度：递归 `1 + max(left, right)`，时间 `O(n)`。
- 判断平衡：后序返回子树高度；发现高度差超过 1 即可提前失败，时间 `O(n)`。
- 最近公共祖先：若根等于任一目标则返回根；左右递归都有结果时根为 LCA，否则返回非空侧。
- 序列化与反序列化：必须编码空节点或结构边界，否则无法唯一恢复形状。

### 3.5 并查集（Union-Find）

用于维护动态连通分量。`find(x)` 找代表元，`union(a,b)` 合并集合。路径压缩与按秩/大小合并组合后，单次操作摊还近似 `O(α(n))`，其中 `α` 为反阿克曼函数，增长极慢。

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        return True
```

## 4. 图与重要算法

### 4.1 表示方法

图由顶点和边组成，可为有向/无向、带权/无权。邻接表空间 `O(V+E)`，适合稀疏图；邻接矩阵空间 `O(V²)`，检查边是否存在为 `O(1)`，适合稠密图。

### 4.2 BFS 与 DFS

- **BFS** 使用队列按距离层推进；无权图中可求从源点到所有点的最短边数距离，复杂度 `O(V+E)`。
- **DFS** 使用递归或显式栈深入探索，可用于连通分量、环检测、拓扑排序等；邻接表复杂度 `O(V+E)`。

遍历前应标记已访问节点，避免重复访问和无限循环。对非连通图，需从每个尚未访问的顶点启动遍历。

### 4.3 最短路

- **Dijkstra**：边权非负；优先队列实现通常为 `O((V+E) log V)`。遇到负权边不能直接用。
- **Bellman–Ford**：允许负权边；松弛所有边 `V-1` 轮，时间 `O(VE)`；再多一轮仍能松弛则存在可达负环。
- **Floyd–Warshall**：求所有点对最短路，时间 `O(V³)`、空间 `O(V²)`；适合顶点数较小或稠密图，可检测负环（对角线变负）。

Dijkstra 核心流程：距离源点初始化为 0，其余为无穷；每次取当前距离最小且未过期的点，对出边执行 `dist[v] = min(dist[v], dist[u] + w)`。

### 4.4 最小生成树（MST）

连通无向带权图中，连接所有顶点且总权值最小的无环边集。

- **Kruskal**：边按权排序，依次尝试加入；用并查集跳过成环边。复杂度 `O(E log E)`。
- **Prim**：从一个顶点出发，每次加入连接树与外部顶点的最小边；堆优化约 `O(E log V)`。

### 4.5 拓扑排序与关键路径概念

有向无环图（DAG）可进行拓扑排序，使每条有向边 `u→v` 中 `u` 排在 `v` 前。Kahn 算法反复取入度为 0 的点，复杂度 `O(V+E)`；若处理点数少于 `V`，图有环。DFS 也可用完成时间逆序得到结果。

### 4.6 强连通分量与二分图

有向图中互相可达的极大顶点集合为强连通分量，可用 Kosaraju 或 Tarjan 算法，均为 `O(V+E)`。二分图能将顶点分成两侧且每条边跨侧；可用 BFS/DFS 染色检查，时间 `O(V+E)`。

## 5. 排序算法

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 |
|---|---:|---:|---:|---|
| 冒泡排序 | `O(n²)` | `O(n²)` | `O(1)` | 稳定 |
| 选择排序 | `O(n²)` | `O(n²)` | `O(1)` | 通常不稳定 |
| 插入排序 | `O(n²)` | `O(n²)` | `O(1)` | 稳定 |
| 归并排序 | `O(n log n)` | `O(n log n)` | `O(n)` | 稳定 |
| 快速排序 | `O(n log n)` | `O(n²)` | 平均 `O(log n)` 栈 | 通常不稳定 |
| 堆排序 | `O(n log n)` | `O(n log n)` | `O(1)` | 不稳定 |
| 计数排序 | `O(n+k)` | `O(n+k)` | `O(n+k)` | 可稳定 |
| 基数排序 | `O(d(n+k))` | `O(d(n+k))` | `O(n+k)` | 依赖稳定的子过程 |

`k` 表示值域大小，`d` 表示位数/轮数。计数、基数排序是非比较排序，依赖键值范围或表示形式，不适用于所有输入。

**稳定排序**指相等键的相对次序保持不变。若要按多字段排序，稳定性常能让分阶段排序正确组合。

### 5.1 核心思路

- 插入排序：维护左侧已排序区，每次把新元素插入正确位置；小数组或近乎有序数据上常有优势。
- 归并排序：分治排序左右两半，再线性合并；稳定、时间有保证，需额外空间。
- 快速排序：选基准并分区，递归处理两侧；随机化或三数取中可降低遇到坏划分的概率，但理论最坏仍为 `O(n²)`。
- 堆排序：建堆后反复取最大/最小元素；原地且时间有保证，但不稳定。

### 5.2 比较排序下界

基于比较的排序在最坏情况下至少需要 `Ω(n log n)` 次比较（决策树下界）。因此要突破该界，必须利用键的额外结构，例如整数值域有限。

## 6. 查找与哈希表

### 6.1 顺序查找与二分查找

顺序查找适用于未排序数据，时间 `O(n)`。二分查找要求序列有序、且通常要求可随机访问，时间 `O(log n)`。

```python
def lower_bound(a, target):
    """返回第一个满足 a[i] >= target 的下标；不存在时返回 len(a)。"""
    lo, hi = 0, len(a)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

半开区间 `[lo, hi)` 可避免部分边界错误。`lower_bound` 得到第一个 `>= target` 的位置；若要找最后一个 `<= target`，可转化为找第一个 `> target` 再减一。每次迭代都应保证搜索区间严格缩小。

### 6.2 哈希表

哈希函数把键映射到桶。理想均匀散列下，查找、插入、删除平均 `O(1)`；冲突严重时最坏可到 `O(n)`。哈希表不保证键的顺序，也不应假定不同键一定有不同哈希值。

冲突处理常见方法：

- **链地址法**：每个桶维护多个条目。
- **开放寻址法**：冲突后探测其他槽位（线性探测、二次探测、双重散列）。

装载因子 `α = 元素数 / 桶数`。扩容与重新散列可降低碰撞密度，但会产生偶发 `O(n)` 操作；插入的摊还成本通常为 `O(1)`。

### 6.3 其他有序查找结构

平衡搜索树支持 `O(log n)` 查找、插入、删除并保持有序；堆只高效支持极值；Trie 适合前缀查找；哈希表适合精确键查询。先根据需要的操作选择结构。

## 7. 算法设计范式

### 7.1 分治法

把问题分成相似子问题，递归求解后合并。典型例子：归并排序、快速排序、二分查找。分析时写出递推式，重点核对子问题规模与合并成本。

### 7.2 贪心法

每一步选择当前看来最优的局部决策。必须证明局部选择能导向全局最优；常见证明为交换论证、贪心选择性质或归纳法。例子：区间调度按结束时间排序；Kruskal 构造 MST。

### 7.3 动态规划

适用于具有**最优子结构**和**重叠子问题**的问题。设计步骤：

1. 定义状态 `dp[...]` 的精确定义。
2. 写出状态转移和边界条件。
3. 确定计算顺序，保证依赖先算好。
4. 计算时间与空间，并按依赖关系压缩空间。

背包 0/1 问题的一维转移：

$$dp[c] = \max(dp[c],\ dp[c-w_i]+v_i)$$

容量 `c` 必须从大到小遍历，避免同一物品被重复使用。完全背包通常从小到大遍历。经典 DP：斐波那契、最长公共子序列、最长递增子序列、网格路径、区间 DP、树形 DP。

### 7.4 回溯与剪枝

回溯按决策树搜索：选择、递归、撤销。适合排列、组合、子集、数独等约束搜索。最坏复杂度常为指数级；剪枝只能跳过已知不可能或不优的分支，不能在没有证明时随意丢弃候选。

### 7.5 分支限界

用于优化问题：搜索状态空间树，并用上界/下界判断某分支不可能优于当前解时剪掉。关键是界必须安全，不能错误排除最优解。

### 7.6 双指针、滑动窗口与前缀和

- 双指针：有序数组两端夹逼、快慢指针等；通常通过指针单调移动做到 `O(n)`。
- 滑动窗口：维护连续区间，适用于满足可增删维护条件的子串/子数组问题。
- 前缀和：`prefix[i] = a[0]+...+a[i-1]`，区间 `[l,r)` 的和为 `prefix[r]-prefix[l]`，预处理 `O(n)`、单次查询 `O(1)`。

### 7.7 位运算与随机化

常用位技巧：`x & 1` 判断奇偶；`x & (x-1)` 清除最低位的 1；异或满足交换、结合且 `a ^ a = 0`。使用前需明确整数位宽和负数表示的语言语义。随机化可改善期望表现（如随机快速排序），但不等于最坏复杂度保证。

| 算法 | 时间 | 空间 | 适用条件/说明 |
|---|---:|---:|---|
| 二分查找 | `O(log n)` | `O(1)` | 有序、可随机访问 |
| BFS / DFS | `O(V+E)` | `O(V)` | 邻接表表示 |
| Dijkstra | `O((V+E)log V)` | `O(V+E)` | 非负边权 |
| Bellman–Ford | `O(VE)` | `O(V)` | 可有负权，可检测负环 |
| Floyd–Warshall | `O(V³)` | `O(V²)` | 所有点对最短路 |
| Kruskal | `O(E log E)` | `O(V+E)` | 无向图，配并查集 |

## 9. 自测题

先尝试独立作答，再对照解析要点。练习时应说明思路、正确性依据、复杂度与边界条件。

1. **分析复杂度**：循环变量从 1 开始，每轮乘 2，直到大于 `n`。复杂度是多少？
2. **链表**：如何用 `O(1)` 额外空间判断单链表是否有环？如何找环入口？
3. **栈**：如何用单调栈求每个元素右侧第一个更大元素？总体复杂度为何不是 `O(n²)`？
4. **树**：BST 删除有两个孩子的节点时，为什么可用中序后继替换？
5. **图**：无权图的最短路径用什么算法？存在负权边时为何不能直接使用 Dijkstra？
6. **MST**：Kruskal 如何判断加入一条边是否成环？
7. **排序**：稳定排序的定义是什么？哪些常用排序稳定？
8. **二分**：`lower_bound` 返回什么？为什么选半开区间？
9. **哈希**：平均 `O(1)` 的前提是什么？最坏为何会退化？
10. **DP**：0/1 背包的一维容量为何倒序遍历？
11. **贪心**：只说“每一步选最小结束时间”是否足够？还需补充什么？
12. **综合设计**：给定大量整数，需频繁查询区间和、但数组不变，如何预处理？

### 解析要点

1. `Θ(log n)`，每轮指数级增大。
2. Floyd 快慢指针；相遇后一个指针回头部，两者同步前进，相遇处为环入口（在常见单链表模型下）。
3. 从右向左维护递减候选栈，弹出不可能成为答案的元素；每个元素最多入栈和出栈各一次，总计 `O(n)`。
4. 后继是右子树中最小节点，替换后仍满足 BST 次序；后继至多只有右孩子，后续删除较简单。
5. BFS；Dijkstra 的“取出当前最小距离后即可定型”依赖非负边权，负边可能使已定型距离变小。
6. 并查集判断两端代表元是否相同；相同则已连通、加入会成环。
7. 相同键元素相对次序不变。常见稳定算法包括冒泡、插入、归并；选择、堆、快速通常不稳定。
8. 返回第一个 `>= target` 的位置；半开区间易表达空区间和结束位置，且循环条件统一为 `lo < hi`。
9. 哈希分布较均匀、负载因子受控；大量键落在相同桶或探测聚集会导致退化。
10. 倒序保证本轮状态使用的是上一轮（未使用当前物品）的结果，防止重复选同一件物品。
11. 还需证明贪心正确性，例如通过交换论证或贪心选择性质；并明确区间端点定义。
12. 建立前缀和；预处理 `O(n)`，每次区间和查询 `O(1)`。

| 第 7 天 | 综合复盘与自测 | 限时完成自测；整理错题与薄弱点 |

### 每次刷题的固定流程

1. 重述输入、输出和约束；确认空输入、重复值、负数、越界等边界。
2. 先给出直接解法，再判断瓶颈来自时间还是空间。
3. 选择数据结构或范式，并解释它为何适合当前操作。
4. 写下循环不变量、状态定义或正确性理由。
5. 手动跟踪一个普通例子和一个边界例子。
6. 报告最坏/平均/摊还复杂度中适用的口径。
7. 复盘错题：记录“误判条件、遗漏边界、错误状态或证明缺口”，隔天重做。

### 复习优先级

优先掌握：复杂度估算、数组/哈希、栈队列、二叉树遍历、二分、排序、BFS/DFS、并查集、基础 DP。进阶再强化：最短路、MST、强连通分量、Trie、线段树/树状数组、字符串高级匹配和复杂状态 DP。
