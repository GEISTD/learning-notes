Java 简介 & 环境搭建

入门

什么是 Java

Java 是一门 面向对象 的编程语言，由 Sun 公司（现在是 Oracle）于 1995 年推出。最大的特点是 "一次编写，到处运行"（Write Once, Run Anywhere），因为 Java 程序运行在 JVM（Java 虚拟机）上，跨平台能力强。

Java SE
标准版，基础语法和核心API，是其他版本的基础
Java EE
企业版，用于开发大型企业级应用（Web、分布式）
Java ME
微型版，用于嵌入式设备（现在用得少了）
应用领域
后端开发、Android、大数据、企业级系统

Java 核心特性

  • 简单：去掉了 C++ 中复杂的指针、多继承、手动内存管理
  • 面向对象：封装、继承、多态
  • 跨平台：JVM 实现 "一次编写，到处运行"
  • 健壮：强类型、异常处理、垃圾回收
  • 安全：沙箱机制，Java Web Start 等
  • 多线程：内置多线程支持

JDK / JRE / JVM 的关系

JDK (Java Development Kit) = 开发工具包 └─ JRE (Java Runtime Environment) = 运行环境 └─ JVM (Java Virtual Machine) = Java虚拟机 + 核心类库 JDK = JRE + 开发工具(javac, java, javadoc...) JRE = JVM + 核心类库 JVM = 真正执行字节码的虚拟机 开发人员装 JDK 就行，因为 JDK 包含了 JRE

第一个 Java 程序

// HelloWorld.java public class HelloWorld { // 类名必须和文件名完全一致 public static void main(String[] args) { // main 方法是程序入口，固定写法 System.out.println("Hello, World!"); // 输出并换行 } } // 编译：生成 .class 字节码文件 // javac HelloWorld.java // 运行：JVM 执行字节码 // java HelloWorld
Java 执行流程
.java 源文件 → javac 编译 → .class 字节码 → JVM 解释执行 → 结果
这就是 Java 跨平台的原理：字节码不针对具体平台，只针对 JVM

面向对象

核心

类与对象

// 定义类 public class Person { // 属性（成员变量） private String name; private int age; // 构造方法：与类同名，无返回值，创建对象时调用 public Person() { } // 无参构造 public Person(String name, int age) { // 有参构造 this.name = name; // this 指代当前对象 this.age = age; } // 方法（行为） public void eat() { System.out.println(name + "在吃饭"); } // getter / setter（封装） public String getName() { return name; } public void setName(String name) { this.name = name; } public int getAge() { return age; } public void setAge(int age) { if (age > 0) this.age = age; // 可以做数据校验 } } // 创建对象 Person p = new Person("张三", 20); p.eat(); // 调用方法 System.out.println(p.getName()); // 获取属性

封装

把属性藏起来（private），通过 public 的 getter/setter 方法访问。好处：

  • 数据安全：可以在 setter 里做校验
  • 隐藏实现：内部怎么存的外面不用管
  • 便于维护：改了内部实现不影响外部使用

private✅❌❌❌

this 关键字

  • this.属性：访问当前对象的成员变量
  • this.方法()：调用当前对象的方法
  • this()：调用本类的其他构造方法（必须在第一行）

static 关键字

代码块

继承与多态

重点难点

继承（extends）

class Animal { // 父类 protected String name; public void eat() { System.out.println("吃饭"); } } class Dog extends Animal { // 子类继承父类 public void bark() { System.out.println("汪汪"); } } // Java 是单继承：一个类只能有一个直接父类 // 所有类都直接或间接继承自 Object 类 // 子类继承父类的非私有成员，private 的不能直接访问

super 关键字

  • super.属性：访问父类的成员变量
  • super.方法()：调用父类的方法
  • super()：调用父类的构造方法（必须在子类构造第一行）
构造方法调用顺序
创建子类对象时，先调用父类构造，再执行子类构造。
如果子类构造第一行没有写 super()，编译器会自动加 super()（调用父类无参构造）。
如果父类没有无参构造，子类必须手动 super(参数) 调用父类有参构造。

方法重写（Override）

class Animal { public void speak() { System.out.println("动物叫"); } } class Cat extends Animal { @Override // 注解：告诉编译器我要重写，写错了会报错 public void speak() { // 重写父类方法 System.out.println("喵喵喵"); } } // 重写的要求：两同两小一大 // 两同：方法名相同、参数列表相同 // 两小：返回值类型更小或相等、抛出异常更小或相等 // 一大：访问权限更大或相等（public > protected > 默认 > private）

多态

// 多态：父类引用指向子类对象 Animal a = new Cat(); a.speak(); // 输出"喵喵喵"（调用的是 Cat 的 speak） // 多态的三个条件： // 1. 有继承关系 // 2. 子类重写父类方法 // 3. 父类引用指向子类对象 // 编译看左边，运行看右边 // - 能不能调用：看父类有没有这个方法（编译时检查） // - 调用谁的：看子类有没有重写（运行时绑定） Animal a2 = new Dog(); a2.bark(); // 编译错误！Animal 里没有 bark 方法 ((Dog)a2).bark(); // 向下转型后可以调用

向上转型 & 向下转型

// 向上转型（自动）：子类 → 父类 Animal a = new Dog(); // 安全 // 向下转型（强制）：父类 → 子类 Dog d = (Dog) a; // 有风险，可能 ClassCastException // 安全转型：用 instanceof 判断 if (a instanceof Dog) { Dog d = (Dog) a; d.bark(); } // Java 16+ 模式匹配 if (a instanceof Dog d) { // 判断成功后直接有 d 变量 d.bark(); }

抽象类（abstract）

abstract class Shape { // 抽象类：包含抽象方法的类 abstract double area(); // 抽象方法：只有声明没有实现 void printInfo() { // 抽象类也可以有普通方法 System.out.println("这是一个图形"); } } class Circle extends Shape { double r; double area() { return 3.14 * r * r; } // 必须实现抽象方法 } // 抽象类不能实例化 // Shape s = new Shape(); // 错误 Shape s = new Circle(); // 可以有多态

接口（interface）

interface Flyable { void fly(); // 抽象方法（默认 public abstract） default void defaultMethod() { // Java 8+ 默认方法 System.out.println("默认方法"); } static void staticMethod() { // Java 8+ 静态方法 System.out.println("静态方法"); } } class Bird implements Flyable { // 实现接口 public void fly() { // 必须实现，且必须是 public System.out.println("鸟在飞"); } } // 接口 vs 抽象类： // 1. 类只能单继承，但可以实现多个接口 // 2. 抽象类有构造方法，接口没有 // 3. 抽象类可以有各种变量，接口只有 public static final 常量 // 4. 抽象类是"是不是"的关系，接口是"能不能"的关系

final 关键字

修饰对象作用
final 类不能被继承（String 就是 final 类）
final 方法不能被重写
final 变量只能赋值一次，变成常量（常量名全大写）
final 引用引用不能变（不能指向新对象），但对象内容可以改

Object 类的常用方法

// Object 是所有类的根类 equals(Object obj) // 判断两个对象是否相等（默认比较地址，一般要重写） hashCode() // 返回对象的哈希码值 toString() // 返回对象的字符串表示（默认是类名@哈希码，一般要重写） getClass() // 返回对象的运行时类（反射用） clone() // 克隆对象（需要实现 Cloneable 接口） finalize() // 垃圾回收时调用（不推荐用） // equals 和 hashCode 的约定： // 1. 两个对象 equals 相等，hashCode 一定相等 // 2. 两个对象 hashCode 相等，equals 不一定相等 // 3. 重写 equals 必须同时重写 hashCode

String 字符串

String 是不可变的
String 对象一旦创建就不能修改。所有的修改方法（substring、replace等）都是返回新字符串，原字符串不变。
频繁拼接字符串用 StringBuilder（非线程安全，快）或 StringBuffer（线程安全，慢）。

异常处理

基础

异常体系

Throwable ├── Error // 严重错误，程序无法处理（OOM、StackOverflowError） └── Exception // 异常，程序可以处理 ├── RuntimeException // 运行时异常，不强制捕获（空指针、数组越界、类型转换...） └── 其他Exception // 受检异常，必须捕获或声明（IOException、SQLException...）

try-catch-finally

try { // 可能出异常的代码 int a = 10 / 0; } catch (ArithmeticException e) { // 捕获并处理 e.printStackTrace(); // 打印异常栈信息 System.out.println("除数不能为0"); } catch (Exception e) { // 多个 catch，从小到大写 System.out.println("其他异常"); } finally { // 不管有没有异常，都会执行（除非退出JVM） // 一般用来释放资源（关流、关连接） System.out.println("finally 执行了"); }
finally 的特殊情况
try 里有 return，finally 也会执行（在 return 之前）。
但如果 finally 里也有 return，会覆盖 try 里的 return（不推荐这么写）。

throws & throw

// throws：声明方法可能抛出异常（甩锅给调用者） public void readFile(String path) throws IOException { // ... } // throw：手动抛出异常 if (age < 0) { throw new IllegalArgumentException("年龄不能为负"); } // 自定义异常 class MyException extends RuntimeException { public MyException(String msg) { super(msg); } }

try-with-resources

// Java 7+ 自动关闭资源，必须实现 AutoCloseable 接口 try (FileInputStream fis = new FileInputStream("a.txt")) { // 使用 fis } catch (IOException e) { e.printStackTrace(); } // 不用手动关，try 结束自动关闭

IO 流

进阶

流的分类

分类方式类型说明
按方向输入流读数据（InputStream / Reader）
输出流写数据（OutputStream / Writer）
按单位字节流按字节读，什么文件都能处理（图片、视频、文本）
字符流按字符读，只能处理文本（自动处理编码）
按功能节点流直接操作数据源（FileInputStream 等）
缓冲流包装节点流，加缓冲区提高效率（Buffered...）

字节流读写文件

// 复制文件（字节流，可用任何文件） try ( FileInputStream fis = new FileInputStream("a.txt"); FileOutputStream fos = new FileOutputStream("b.txt") ) { byte[] buf = new byte[1024]; int len; while ((len = fis.read(buf)) != -1) { fos.write(buf, 0, len); } } catch (IOException e) { e.printStackTrace(); } // 缓冲流：更快 BufferedInputStream bis = new BufferedInputStream(new FileInputStream("a.txt")); BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("b.txt"));

字符流读写文件

// 字符流：只能读文本，但更方便 try ( FileReader fr = new FileReader("a.txt"); FileWriter fw = new FileWriter("b.txt") ) { char[] buf = new char[1024]; int len; while ((len = fr.read(buf)) != -1) { fw.write(buf, 0, len); } } // 缓冲字符流：有 readLine() 和 newLine() 方法，按行读写 try ( BufferedReader br = new BufferedReader(new FileReader("a.txt")); BufferedWriter bw = new BufferedWriter(new FileWriter("b.txt")) ) { String line; while ((line = br.readLine()) != null) { bw.write(line); bw.newLine(); } }

多线程

重点

进程 vs 线程

  • 进程：一个运行中的程序，有独立的内存空间
  • 线程：进程里的执行路径，一个进程可以有多个线程，共享进程资源
  • 进程切换开销大，线程切换开销小

创建线程的三种方式

// 方式1：继承 Thread 类 class MyThread extends Thread { @Override public void run() { for (int i = 0; i < 10; i++) { System.out.println(getName() + ": " + i); } } } // 启动：new MyThread().start(); // 方式2：实现 Runnable 接口（推荐，因为可以继承其他类） class MyRunnable implements Runnable { @Override public void run() { System.out.println(Thread.currentThread().getName()); } } // 启动：new Thread(new MyRunnable()).start(); // 方式3：实现 Callable 接口（有返回值） class MyCallable implements Callable { @Override public Integer call() throws Exception { return 100; } } // 配合 FutureTask 获取返回值

线程的生命周期

新建(NEW) → 就绪(RUNNABLE) → 运行(RUNNING) → 终止(TERMINATED) ↑ ↓ └── 阻塞(WAITING/TIMED_WAITING/BLOCKED) ←┘ // 常用方法 Thread.currentThread() // 当前线程对象 Thread.sleep(1000) // 休眠（毫秒），不会释放锁 t.start() // 启动线程（不要直接调run！） t.join() // 等待该线程执行完 t.setPriority(10) // 设置优先级（1~10，默认5） t.setDaemon(true) // 设置为守护线程（用户线程结束，守护线程也结束） t.interrupt() // 中断线程 t.yield() // 让出CPU，回到就绪状态

线程安全与 synchronized

// 多个线程同时操作共享数据时，会出现线程安全问题 // 解决方案：加锁 synchronized // 方式1：同步代码块 synchronized (锁对象) { // 需要同步的代码 } // 方式2：同步方法（锁是 this） public synchronized void method() { } // 方式3：静态同步方法（锁是 类.class） public static synchronized void method() { }

Lock 锁

import java.util.concurrent.locks.ReentrantLock; class MyClass { private ReentrantLock lock = new ReentrantLock(); public void method() { lock.lock(); // 加锁 try { // 业务代码 } finally { lock.unlock(); // 解锁（一定要在finally里） } } } // synchronized vs Lock： // 1. synchronized 是关键字，JVM实现；Lock 是接口，代码实现 // 2. synchronized 自动释放锁；Lock 必须手动释放 // 3. Lock 功能更多：可中断、可超时、可公平锁

死锁

两个线程互相持有对方想要的锁，都不肯释放，就会产生死锁。

产生条件：互斥、持有并等待、不可剥夺、循环等待

避免方法：破坏其中一个条件即可，比如按固定顺序加锁

JVM 基础

进阶

JVM 内存区域

区域作用线程共享/私有
堆（Heap）存对象实例和数组，GC主要区域共享
方法区（Method Area）类信息、常量、静态变量、JIT编译代码共享
虚拟机栈每个方法调用一个栈帧，存局部变量、操作数栈等私有
本地方法栈为 native 方法服务私有
程序计数器记录当前线程执行到哪条字节码私有

堆内存分代

堆（Heap） ├── 新生代（Young） │ ├── Eden 区 // 新对象都在这 │ ├── Survivor 0 // 存活区 │ └── Survivor 1 // 存活区 └── 老年代（Old） // 长期存活的对象 // 默认比例：新生代:老年代 = 1:2 // Eden:S0:S1 = 8:1:1 // Minor GC：回收新生代，频繁，快 // Major GC/Full GC：回收老年代+新生代，慢

垃圾回收（GC）

// 哪些对象可以回收？ // 可达性分析：从 GC Roots 出发，不可达的对象可以回收 // GC Roots：栈中引用的对象、静态变量引用的对象、常量引用的对象等 // 垃圾回收算法： // 1. 标记-清除：标记后直接清除 → 有内存碎片 // 2. 复制算法：两块区域，把存活的复制过去 → 没有碎片，但浪费空间（新生代用） // 3. 标记-整理：标记后把存活的移到一起 → 没有碎片，但要移动（老年代用） // 4. 分代收集：新生代用复制，老年代用标记-整理

类加载过程

加载 → 验证 → 准备 → 解析 → 初始化 → 使用 → 卸载 \____ 连接 ____/ // 加载：读字节码，生成Class对象 // 验证：确保字节码符合规范 // 准备：给静态变量分配内存，赋默认值 // 解析：符号引用变直接引用 // 初始化：执行静态代码块和静态变量赋值

类加载器

Bootstrap ClassLoader // 启动类加载器：加载核心类库（rt.jar） ↑ Extension ClassLoader // 扩展类加载器：加载扩展类（jre/lib/ext） ↑ Application ClassLoader // 应用程序类加载器：加载用户类路径的类 ↑ 自定义 ClassLoader // 自己写的类加载器 // 双亲委派模型： // 收到类加载请求，先让父加载器去加载 // 父加载器加载不了，自己才加载 // 好处：安全（核心类不会被篡改）、避免重复加载

面试高频问题速答

面试专用
问题参考回答
== 和 equals 的区别？ == 比较基本类型是比较值，比较引用类型是比较地址
equals 默认比较地址（Object的实现），很多类（String、Integer等）重写了 equals 来比较内容
比较字符串内容一定要用 equals
String 为什么不可变？ String 内部用 final 修饰的 char 数组存储（Java 9 后是 byte 数组），并且没有提供修改它的方法。不可变的好处：可以共享字符串常量池、安全、哈希值可以缓存
String、StringBuilder、StringBuffer 区别？ String 不可变，频繁拼接会产生很多临时对象
StringBuilder 可变，非线程安全，快（推荐单线程用）
StringBuffer 可变，线程安全（synchronized），慢（多线程用）
重载和重写的区别？ 重载（Overload）：同一类中，方法名相同参数不同，编译时多态
重写（Override）：父子类中，方法名参数返回值都相同，运行时多态
接口和抽象类的区别？ 1. 类只能单继承，但可以实现多个接口
2. 抽象类有构造方法，接口没有
3. 抽象类可以有各种成员变量，接口只有常量
4. 抽象类是"是不是"，接口是"能不能"
Java 只有值传递？ 是的。基本类型传值的副本，引用类型传引用的副本（地址值）。改形参本身不会影响实参，但通过引用可以改对象的内容
final 关键字的作用？ final 类：不能被继承
final 方法：不能被重写
final 变量：只能赋值一次，变成常量
final 引用：不能指向新对象，但对象内容可以改
static 关键字的作用？ 静态变量：所有对象共享，属于类，在方法区
静态方法：属于类，只能访问静态成员，没有this
静态代码块：类加载时执行，只执行一次，用来初始化
HashMap 的底层原理？ JDK1.7：数组+链表，头插法
JDK1.8：数组+链表+红黑树，尾插法。链表长度超过8且数组长度超过64时转红黑树，提高查询效率（O(n) → O(logn)）
默认容量16，负载因子0.75，扩容为原来的2倍
HashMap 和 Hashtable 的区别？ HashMap 非线程安全，允许 null 键值，效率高
Hashtable 线程安全（方法加 synchronized），不允许 null，效率低
多线程推荐用 ConcurrentHashMap
ArrayList 和 LinkedList 的区别？ ArrayList 底层是动态数组，随机访问快，中间插入删除慢（要移动元素）
LinkedList 底层是双向链表，随机访问慢，头尾插入删除快
一般情况用 ArrayList 就行
sleep 和 wait 的区别？ 1. sleep 是 Thread 的静态方法，wait 是 Object 的方法
2. sleep 不会释放锁，wait 会释放锁
3. sleep 不需要在同步块中，wait 需要
4. sleep 到时间自动醒，wait 需要 notify/notifyAll 唤醒
synchronized 和 Lock 的区别？ synchronized 是关键字，JVM实现，自动释放锁，不可中断
Lock 是接口，代码实现，手动释放锁（finally），可中断、可超时、可公平锁
什么是死锁？怎么避免？ 两个或多个线程互相持有对方需要的锁，都不释放，永久等待。
四个必要条件：互斥、持有并等待、不可剥夺、循环等待
避免方法：破坏任一条件，比如按固定顺序加锁
JVM 内存结构？ 线程共享：堆（对象）、方法区（类信息、常量、静态变量）
线程私有：虚拟机栈（栈帧-局部变量表等）、本地方法栈、程序计数器
垃圾回收算法有哪些？ 标记-清除：快，但有碎片
复制算法：无碎片，但浪费空间（新生代用，Eden+Survivor）
标记-整理：无碎片，但要移动对象（老年代用）
分代收集：新生代复制算法，老年代标记-整理
什么是双亲委派模型？ 类加载时先让父加载器加载，父加载器加载不了自己才加载。
好处：保证核心类的安全（不会被篡改）、避免重复加载
层级：Bootstrap → Extension → Application → 自定义
强软弱虚四种引用？ 强引用：new 出来的，OOM 也不回收
软引用（SoftReference）：内存不足时回收（缓存用）
弱引用（WeakReference）：下次 GC 就回收
虚引用（PhantomReference）：跟踪对象回收，get 不到
JDK 和 JRE 的区别？ JDK = JRE + 开发工具（javac, java, javadoc等）
JRE = JVM + 核心类库
开发人员装 JDK，只运行程序装 JRE 就行
