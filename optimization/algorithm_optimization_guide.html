什么是算法

入门

算法就是解决问题的步骤和方法。就像菜谱——要做一道菜，需要哪些食材、先放什么后放什么、火候多大、炒多久，这就是算法。

输入
算法有 0 个或多个输入（已知条件）
输出
算法至少有一个输出（问题的解）
确定性
每一步都是明确的，不会有歧义
有穷性
执行有限步后一定会结束
可行性
每一步都能通过有限次操作完成

为什么要学算法？

  • 面试必备：大厂技术岗面试必考算法
  • 解决问题能力：学会把复杂问题拆解成可计算的步骤
  • 写出更优的代码：知道什么方案快、什么方案慢
  • 思维训练：锻炼逻辑思维和抽象能力

算法的分类

按解题思想分： ├── 暴力枚举 最简单，遍历所有可能 ├── 分治算法 大问题拆成小问题，分别解决再合并 ├── 动态规划 记住子问题的解，避免重复计算 ├── 贪心算法 每一步选当前最优，希望全局最优 ├── 回溯算法 一条路走到底，走不通就退回来 └── 图论算法 针对图结构的算法（BFS/DFS/最短路等） 按应用场景分： ├── 排序算法 冒泡/选择/插入/快排/归并/堆排序 ├── 搜索算法 二分查找/DFS/BFS ├── 字符串算法 KMP/正则/Trie树 ├── 数学算法 素数/最大公约数/快速幂 └── 几何算法 凸包/最近点对

时间 & 空间复杂度分析

必会核心

为什么需要复杂度分析？

同一个问题可以有多种解法，怎么判断哪个更好？跑一下测时间？不行，因为不同机器、不同数据量结果不一样。我们需要一种不依赖具体环境的分析方法——这就是复杂度分析。

大 O 表示法（Big O Notation）

描述算法随数据量增长，运行时间/占用空间的增长趋势。只看最高阶项，忽略常数和低阶项。

// 例子：计算 1+2+...+n // 方法1：循环累加 → O(n) int sum = 0; for (int i = 1; i <= n; i++) sum += i; // 方法2：公式计算 → O(1) int sum = n * (n + 1) / 2; // 显然方法2更好，不管n多大都是一步搞定

常见时间复杂度（从快到慢）

复杂度名称例子n=1000时的操作数
O(1)常数阶数组下标访问、哈希表查找1
O(log n)对数阶二分查找10
O(n)线性阶遍历数组、顺序查找1,000
O(n log n)线性对数阶快速排序、归并排序10,000
O(n²)平方阶冒泡排序、双重循环1,000,000
O(n³)立方阶三重循环、Floyd算法1,000,000,000
O(2ⁿ)指数阶递归斐波那契天文数字！
O(n!)阶乘阶全排列想都不敢想
经验法则
一般 OJ 评测机 1 秒约等于 10^7 ~ 10^8 次操作。
如果 n = 10^5，O(n²) = 10^10 → 超时！只能用 O(n log n) 及以下的算法。

怎么分析时间复杂度？

// 规则1：只看循环次数最多的那层 for (int i = 0; i < n; i++) { // n次 for (int j = 0; j < n; j++) { // n次 → 总共 n*n = n² 次 // ... } } // O(n²) // 规则2：每次砍一半 → log n while (n > 1) { n = n / 2; } // 多少次？log2(n) 次 → O(log n) // 规则3：并列的相加，取最大的 for (...) { } // O(n) for (...) { // O(n²) for (...) { } } // 总复杂度 = O(n + n²) = O(n²) （取最大的） // 规则4：递归的复杂度 = 递归次数 × 每次的工作量

空间复杂度

算法运行过程中需要的额外内存空间的增长趋势（不算输入数据本身）。

// O(1) 空间：只用了几个变量 int max(int a, int b) { return a > b ? a : b; } // O(n) 空间：开了一个长度为n的数组 int[] dp = new int[n]; // O(n²) 空间：开了二维数组 int[][] dp = new int[n][n];

最好、最坏、平均情况

// 顺序查找：在数组里找一个数 int search(int[] arr, int target) { for (int i = 0; i < arr.length; i++) { if (arr[i] == target) return i; } return -1; } 最好情况：第一个就是 → O(1) 最坏情况：最后一个才是（或没有） → O(n) 平均情况：假设概率均匀 → O(n/2) = O(n) // 面试和分析时，一般说的是「最坏时间复杂度」

排序算法

必会

七大排序对比

算法平均时间最坏空间稳定性思想
冒泡排序O(n²)O(n²)O(1)✅ 稳定交换
选择排序O(n²)O(n²)O(1)❌ 不稳定选择
插入排序O(n²)O(n²)O(1)✅ 稳定插入
希尔排序O(n^1.3)O(n²)O(1)❌ 不稳定分组插入
快速排序O(n log n)O(n²)O(log n)❌ 不稳定分治
归并排序O(n log n)O(n log n)O(n)✅ 稳定分治
堆排序O(n log n)O(n log n)O(1)❌ 不稳定选择
什么是稳定排序？
如果两个相等的元素，排序后相对位置不变，就是稳定排序。
比如 [3a, 2, 3b] 排序后，如果 3a 还在 3b 前面，就是稳定的。

1. 冒泡排序

// 思想：相邻元素两两比较，大的往后冒，像气泡往上浮 void bubbleSort(int[] arr) { int n = arr.length; for (int i = 0; i < n - 1; i++) { boolean swapped = false; for (int j = 0; j < n - 1 - i; j++) { if (arr[j] > arr[j+1]) { int tmp = arr[j]; arr[j] = arr[j+1]; arr[j+1] = tmp; swapped = true; } } if (!swapped) break; // 优化：这轮没交换说明已经有序了 } } // 口诀：外层 n-1 轮，内层每轮少一个

2. 选择排序

// 思想：每轮选最小的放到前面 void selectionSort(int[] arr) { int n = arr.length; for (int i = 0; i < n - 1; i++) { int minIdx = i; for (int j = i + 1; j < n; j++) { if (arr[j] < arr[minIdx]) minIdx = j; } // 把最小的和第i位交换 int tmp = arr[i]; arr[i] = arr[minIdx]; arr[minIdx] = tmp; } }

3. 插入排序

// 思想：像打牌一样，把新牌插入到前面已经排好的牌里 void insertionSort(int[] arr) { int n = arr.length; for (int i = 1; i < n; i++) { int key = arr[i]; int j = i - 1; // 前面比key大的都往后移 while (j >= 0 && arr[j] > key) { arr[j+1] = arr[j]; j--; } arr[j+1] = key; // 插入到正确位置 } } // 对几乎有序的数组特别快，接近 O(n)

4. 快速排序（重点！）

// 思想：选一个基准(pivot)，小的放左边，大的放右边，递归排序左右 void quickSort(int[] arr, int left, int right) { if (left >= right) return; int pivotIdx = partition(arr, left, right); quickSort(arr, left, pivotIdx - 1); quickSort(arr, pivotIdx + 1, right); } int partition(int[] arr, int left, int right) { int pivot = arr[right]; // 选最右边做基准 int i = left - 1; // 小于基准的区域的边界 for (int j = left; j < right; j++) { if (arr[j] <= pivot) { i++; int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp; } } // 把基准放到中间 int tmp = arr[i+1]; arr[i+1] = arr[right]; arr[right] = tmp; return i + 1; } // 平均 O(n log n)，最坏 O(n²)（已排序的数组） // 优化：随机选基准、三数取中

5. 归并排序

// 思想：分治。拆成两半，分别排序，再合并 void mergeSort(int[] arr, int left, int right) { if (left >= right) return; int mid = left + (right - left) / 2; mergeSort(arr, left, mid); // 排左半边 mergeSort(arr, mid + 1, right); // 排右半边 merge(arr, left, mid, right); // 合并两个有序数组 } void merge(int[] arr, int left, int mid, int right) { int[] tmp = new int[right - left + 1]; int i = left, j = mid + 1, k = 0; while (i <= mid && j <= right) { tmp[k++] = arr[i] <= arr[j] ? arr[i++] : arr[j++]; } while (i <= mid) tmp[k++] = arr[i++]; while (j <= right) tmp[k++] = arr[j++]; // 复制回去 for (i = 0; i < k; i++) arr[left + i] = tmp[i]; } // 时间：O(n log n) 空间：O(n) 稳定排序
排序怎么选？
数据量小：插入排序（n<50 时很快）
数据量大：快速排序（平均最快）
要稳定：归并排序
内存紧张：堆排序（O(1) 额外空间）
实际开发：直接用语言自带的 sort（Java 用双轴快排 + 归并 + 插入的混合排序）

搜索算法

重点

1. 二分查找

在有序数组中查找某值，每次砍一半，O(log n)。

// 基础版：找一个数 int binarySearch(int[] arr, int target) { int left = 0, right = arr.length - 1; while (left <= right) { int mid = left + (right - left) / 2; // 防止溢出，不要写 (left+right)/2 if (arr[mid] == target) { return mid; } else if (arr[mid] < target) { left = mid + 1; // 目标在右边 } else { right = mid - 1; // 目标在左边 } } return -1; // 没找到 } // 进阶：找左边界（第一个等于target的位置） int leftBound(int[] arr, int target) { int left = 0, right = arr.length; while (left < right) { int mid = left + (right - left) / 2; if (arr[mid] < target) { left = mid + 1; } else { right = mid; } } return left; // 找不到时返回应该插入的位置 }
二分查找的核心
二分的本质不是"有序"，而是"可以通过中间元素判断答案在哪一边"。
很多问题都可以用二分，比如：找满足条件的最小值/最大值、平方根、吃香蕉问题等。

2. DFS（深度优先搜索）

一条路走到底，走不通就退回来换一条路。用递归或栈实现。

// 例子：二叉树的前序遍历（DFS） void dfs(TreeNode root) { if (root == null) return; // 终止条件 System.out.println(root.val); // 处理当前节点 dfs(root.left); // 走左边 dfs(root.right); // 走右边 } // DFS 模板： // 1. 终止条件：越界/不满足/找到了 // 2. 标记访问过（防止重复走） // 3. 尝试所有可能的方向 // 4. 回溯（撤销标记）

3. BFS（广度优先搜索）

一层一层往外扩散，像水波一样。用队列实现。最适合找最短路径。

// 例子：二叉树的层序遍历（BFS） void bfs(TreeNode root) { if (root == null) return; Queue q = new LinkedList<>(); q.offer(root); while (!q.isEmpty()) { int size = q.size(); // 当前层的节点数 for (int i = 0; i < size; i++) { TreeNode node = q.poll(); System.out.println(node.val); // 处理 if (node.left != null) q.offer(node.left); if (node.right != null) q.offer(node.right); } } } // BFS 适合：最短路径、层序遍历、最少操作次数
DFS vs BFS 怎么选？
选 DFS：找所有路径、空间要求低、路径长度不重要
选 BFS：找最短路径、层序遍历、最少步数
图搜索要注意：必须记录 visited，否则会重复访问死循环

动态规划（DP）

重难点

什么是动态规划？

把大问题拆成小问题，记住小问题的答案，避免重复计算。核心是 状态转移方程。

大问题 → 拆成子问题 → 求子问题解 → 存起来（DP数组）→ 组合出大问题的解

DP 解题五步法

1. 确定 dp 数组含义
dp[i] 或 dp[i][j] 表示什么？想清楚
2. 推导状态转移方程
dp[i] 怎么从前面的 dp 推出来？这是核心
3. 初始化 dp 数组
base case 是什么？dp[0]、dp[1] 等于多少？
4. 确定遍历顺序
从前往后还是从后往前？外层什么内层什么？
5. 手动推导验证
用小例子手动算一遍，看看对不对

经典入门题：斐波那契数列

// 暴力递归：O(2^n)，慢得离谱！ int fib(int n) { if (n <= 1) return n; return fib(n-1) + fib(n-2); } // DP 解法：O(n) 时间，O(n) 空间 int fibDP(int n) { if (n <= 1) return n; int[] dp = new int[n+1]; dp[0] = 0; dp[1] = 1; for (int i = 2; i <= n; i++) { dp[i] = dp[i-1] + dp[i-2]; // 状态转移方程 } return dp[n]; } // 优化空间：O(1)（只需要前两个状态） int fibBest(int n) { if (n <= 1) return n; int a = 0, b = 1, c; for (int i = 2; i <= n; i++) { c = a + b; a = b; b = c; } return b; }

经典入门题：爬楼梯

// 题目：一次可以爬1阶或2阶，爬n阶有多少种方法？ int climbStairs(int n) { if (n <= 2) return n; int[] dp = new int[n+1]; dp[1] = 1; // 1阶只有1种方法 dp[2] = 2; // 2阶有2种（1+1 或 2） for (int i = 3; i <= n; i++) { // 爬到第i阶 = 从i-1爬1步上来 + 从i-2爬2步上来 dp[i] = dp[i-1] + dp[i-2]; } return dp[n]; }

经典题：01 背包

// 题目：有n个物品，每个物品重量w[i]，价值v[i]，背包容量c，最多装多少价值？ int knapsack(int[] w, int[] v, int c) { int n = w.length; int[][] dp = new int[n+1][c+1]; // dp[i][j] = 前i个物品，容量j，最大价值 for (int i = 1; i <= n; i++) { for (int j = 1; j <= c; j++) { if (j < w[i-1]) { dp[i][j] = dp[i-1][j]; // 装不下，不选 } else { // 选或不选，取最大的 dp[i][j] = Math.max(dp[i-1][j], dp[i-1][j-w[i-1]] + v[i-1]); } } } return dp[n][c]; } // 空间优化：一维DP（倒序遍历！） int knapsackOpt(int[] w, int[] v, int c) { int[] dp = new int[c+1]; for (int i = 0; i < w.length; i++) { for (int j = c; j >= w[i]; j--) { // 倒序！ dp[j] = Math.max(dp[j], dp[j-w[i]] + v[i]); } } return dp[c]; }

常见 DP 题型

题型代表题状态定义

背包 DP01背包、完全背包、多重背包dp[i][j] 前i个物品容量j的最大价值

贪心算法

重点

什么是贪心？

每一步都选当前最优的选择，希望最终得到全局最优。

贪心的前提
不是所有问题都能用贪心！必须满足贪心选择性质（局部最优能导致全局最优）。
怎么判断？一般用反证法 + 数学归纳法证明。或者你想不到反例，那就试试贪心。

经典题：买卖股票最佳时机 II

// 题目：可以多次买卖股票，问最大利润 // 贪心：只要今天比昨天贵，就赚差价 int maxProfit(int[] prices) { int profit = 0; for (int i = 1; i < prices.length; i++) { if (prices[i] > prices[i-1]) { profit += prices[i] - prices[i-1]; } } return profit; }

经典题：跳跃游戏

// 题目：数组每个元素代表在该位置可以跳的最大长度，问能不能跳到最后 boolean canJump(int[] nums) { int farthest = 0; // 当前能跳到的最远位置 for (int i = 0; i < nums.length; i++) { if (i > farthest) return false; // 连这都到不了，更别说后面了 farthest = Math.max(farthest, i + nums[i]); // 更新最远位置 if (farthest >= nums.length - 1) return true; } return true; }

经典题：分发饼干

// 题目：每个孩子有胃口值g，每块饼干大小s，s[i] >= g[i] 才能满足，最多满足几个孩子？ int findContentChildren(int[] g, int[] s) { Arrays.sort(g); Arrays.sort(s); int i = 0, j = 0, count = 0; while (i < g.length && j < s.length) { if (s[j] >= g[i]) { // 这块饼干能满足这个孩子 count++; i++; j++; } else { j++; // 饼干太小，换下一块 } } return count; } // 贪心策略：最小的饼干给胃口最小的孩子（先排序）

贪心 vs DP 怎么选？

对比贪心动态规划
思路每步选当前最优考虑所有可能，选全局最优
效率高，一般 O(n) 或 O(n log n)较低，一般 O(n²) 或更高
正确性需要证明，容易错一般都是对的
适用满足贪心选择性质的问题有重叠子问题和最优子结构
怎么判断举反例，举不出就试试能拆成子问题，子问题能推出大问题

优化的核心思路

1. 先跑对再优化
先写正确的暴力解法，再一步步优化。不要上来就追求最优
2. 找瓶颈
用 profiler 测，不要猜。80% 的时间花在 20% 的代码上
3. 空间换时间
缓存、哈希表、DP数组——用内存换速度
4. 减少重复计算
凡是算过的就存起来，下次直接用（记忆化、DP）
5. 降维打击
O(n²) → O(n log n) → O(n) → O(log n)，每降一级都是质的飞跃
6. 过早优化是万恶之源
除非真的有性能问题，否则不要为了优化而优化，可读性更重要

面试高频问题速答

面试专用
问题参考回答
时间复杂度和空间复杂度是什么？ 时间复杂度描述算法运行时间随数据量增长的趋势，空间复杂度描述额外占用内存的增长趋势。用大O表示法，只看最高阶项。常见的有 O(1), O(log n), O(n), O(n log n), O(n²) 等
常见排序算法及复杂度？ 冒泡、选择、插入 O(n²)；快排、归并、堆排序 O(n log n)。
稳定的：冒泡、插入、归并
快排最坏 O(n²)，平均 O(n log n)，实际最快
快速排序的原理？ 选一个基准(pivot)，把小于基准的放左边，大于的放右边（partition过程），然后递归排序左右两边。平均 O(n log n)，最坏 O(n²)（已排序数组），可以通过随机选基准优化
归并排序的原理？ 分治思想。把数组从中间分成两半，分别排序，然后合并两个有序数组。时间稳定 O(n log n)，空间 O(n)，稳定排序
堆排序的原理？ 先建堆（大顶堆/小顶堆），然后每次把堆顶和最后一个元素交换，调整堆，重复直到有序。时间 O(n log n)，空间 O(1)，不稳定
二分查找的时间复杂度？为什么？ O(log n)。因为每次查找都排除一半的元素，n 经过多少次除以 2 变成 1？就是 log2(n) 次
DFS 和 BFS 的区别？ DFS 是深度优先，一条路走到黑再回溯，用递归或栈实现，适合找所有路径、空间要求低。
BFS 是广度优先，一层一层扩散，用队列实现，适合找最短路径、最少步数。
什么是动态规划？ 把大问题拆成重叠的子问题，记住子问题的解（DP数组），避免重复计算。核心是找到状态转移方程。关键特征：重叠子问题 + 最优子结构
贪心和动态规划的区别？ 贪心每一步选当前最优，不能回退，需要满足贪心选择性质才能用，效率高但不一定对。
动态规划考虑所有可能的选择，通过子问题的最优解推出全局最优解，一定对但效率低一些。
什么是哈希表？怎么解决冲突？ 通过哈希函数把 key 映射到数组下标，实现 O(1) 平均查找。
冲突解决：1.链地址法（Java HashMap用）2.开放地址法（线性探测）3.再哈希法
负载因子超过阈值时会扩容（rehash）
什么是红黑树？ 一种自平衡的二叉搜索树，通过颜色约束和旋转维持近似平衡（最长路径不超过最短路径的2倍）。查找、插入、删除都是 O(log n)。相比 AVL 树，插入删除更快（旋转少），Java 的 TreeMap/TreeSet 用的就是红黑树
堆是什么？应用场景？ 堆是完全二叉树，分大顶堆和小顶堆。堆顶是最值。插入删除 O(log n)，取最值 O(1)。
应用：优先级队列、Top K 问题、堆排序
什么是分治法？ 把大问题分成若干个相同的小问题，递归解决小问题，再把结果合并。
三步走：分解 → 解决 → 合并
例子：归并排序、快速排序、二分查找
什么是回溯算法？ 一种暴力搜索方法，一条路走到底，走不通就退回去换一条路。本质是 DFS + 剪枝。
模板：做出选择 → 递归 → 撤销选择
应用：全排列、组合、子集、N皇后、解数独
怎么分析递归算法的复杂度？ 时间复杂度 = 递归的节点数 × 每个节点的处理时间
空间复杂度 = 递归深度 + 额外空间
可以用主定理（Master Theorem）快速判断分治算法的复杂度
