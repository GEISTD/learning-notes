# NumPy 手写 kNN 与留一法交叉验证

本例使用 NumPy 手写 kNN 分类器，并在 Iris 数据集上比较 `k=1..15` 的留一法（LOO）准确率。

## 手写实现

- **距离计算**：直接用 NumPy 计算欧氏距离，并按距离排序选取最近的 k 个样本。
- **投票逻辑**：统计近邻类别票数；平票时选择最近邻中先出现的类别。
- **特征归一化**：手写 min-max 归一化；常量特征列映射为 0。
- **留一法验证**：每次留出一个样本作为测试集，其余样本用于训练。

每一折的归一化最小值和范围只从该折的训练数据计算，再应用于测试样本，避免数据泄漏。scikit-learn 仅用于加载 Iris 数据集，不用于分类、距离或归一化。

## 运行

在本目录运行：

```bash
python -m pip install -r requirements.txt
python knn_loo.py
```

脚本会打印每个 k 的准确率和最佳 k，并保存、显示 `knn_loo_accuracy.png`。
