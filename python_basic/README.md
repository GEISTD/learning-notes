# Python 基础练习（9 关）

C++ 写多了以后，Python 语法看得懂，但真要让写就卡住。所以拆成 9 个小文件，每关只改函数体，跑一下就知道过没过。

## 用法

```bash
python check.py          # 检查全部
python check.py s02      # 只检查第 2 关
python s05_control.py    # 单跑一关
```

输出 `[通过]` 就是过了，`[未过]` 会打印期望值和实际返回值。

## 自己定的规矩

- 卡住十分钟再看文件顶部的提示，看完还是要自己敲。
- 一关全部通过再进下一关，第 2 关的切片后面到处都要用。
- 写完把每行在干什么讲一遍，讲不清就是没真懂。
- 每周挑一关把实现删掉重写。

## 节奏

一天 20~30 分钟一关，第 9 关拆两三天，整体十来天走完。

`check.py` 的进度被每日计划脚本读走，早上推送里会写今天该过哪几个函数。

## 目录

```
python_basic/
├── check.py             检测入口

```

每个文件自成一体：顶部知识点（带 C++ 对照），中间待实现的函数，底部测试。只改中间，别动测试。
