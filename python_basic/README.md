# Python 基础训练营（手生 → 上手）

给「懂语法但写不出来」的人用的 9 关渐进练习。每关一个 `.py` 文件，**直接在 IDE 里改函数体**，跑一下就知道过没过。

## 怎么用

在 `python_basic` 目录下打开 VS Code，然后：

```bash
python check.py          # 检查全部 9 关
python check.py s02      # 只检查第 2 关
python s05_control.py    # 只跑第 5 关（效果和上面一样）
```

看到 `[通过]` 就是过关，`[未过]` 会直接告诉你「期望什么、你返回了什么」。

## 过关标准（重要）

- **不许先看答案**。卡住超过 10 分钟，允许看文件顶部提示，但仍要自己敲。
- 每关全部 `[通过]` 才进下一关，不要跳关（第 2 关的切片是后面所有题的地基）。
- 写完一段代码，**用嘴讲一遍**："这行在干什么" —— 讲不清就是没懂。
- 每周至少重做一关（把实现删掉重写），这是防遗忘的唯一有效手段。

## 节奏建议

- 每天 **20-30 分钟 / 1 关**，第 9 关可以拆成 2-3 天。整体 10-12 天走完。
- **已接入每日计划**：每天早上 8:30 的推送会自动读取本目录的真实进度（跑一遍测试得出），
  把「第 N 关 + 今天要过哪几个函数」直接写进计划第 2 段，暂替原来的 LeetCode 闯关。
- 9 关全部 `[通过]` 后，每日计划会自动切回 LeetCode 算法闯关，不用你手动改配置。
