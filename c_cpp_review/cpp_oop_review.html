指针与内存管理

重难点

指针基础

int a = 10; int *p = &a; // p 指向 a 的地址 *p = 20; // *p 就是 a，改 *p 就是改 a // 现在 a = 20 // 指针大小：32位=4字节，64位=8字节 // 指针类型决定了 *p 读多少字节、怎么解析

指针与数组

int arr[5] = {1,2,3,4,5}; int *p = arr; // arr 是首元素地址 // 以下等价： arr[2] == *(arr+2) == p[2] == *(p+2) // 指针 +1 = 地址 + sizeof(类型) // 指针运算： p++; // 向后移一个元素 p--; // 向前移一个元素 p - arr; // 两个指针相减 = 相差几个元素

二级指针 & 指针数组 & 数组指针

// 二级指针：指向指针的指针 int a = 10; int *p = &a; int **pp = &p; // **pp == *p == a // 指针数组：数组里存的是指针 char *names[3] = {"张三", "李四", "王五"}; // names[0] 是"张三"的地址 // 数组指针：指向数组的指针 int (*p)[5]; // 指向一个 int[5] 的数组 // 常用来指向二维数组的一行

函数指针

int add(int a, int b) { return a+b; } int (*p)(int, int); // 函数指针：返回int，两个int参数 p = add; p(1, 2); // 调用，结果=3 // 典型用途：回调函数、qsort 比较函数

动态内存分配（堆内存）

// 栈内存：自动分配自动释放，小，快 // 堆内存：手动申请手动释放，大，慢一点 int *p = (int*)malloc(10 * sizeof(int)); // 申请 10 个 int 的空间，返回首地址 int *p2 = (int*)calloc(10, sizeof(int)); // 申请并初始化为0 p = (int*)realloc(p, 20 * sizeof(int)); // 扩容到 20 个 int free(p); // 释放！必须释放，否则内存泄漏 p = NULL; // 置空，避免野指针
常见内存错误
1. 内存泄漏：malloc 了不 free
2. 野指针：指针没初始化或释放后还使用
3. 空指针解引用：NULL 指针直接 *p
4. 越界访问：数组下标超了
5. 重复释放：同一块内存 free 两次
6. 栈溢出：局部数组太大或递归太深

面向对象（OOP）

核心

三大特性

封装（Encapsulation）
把数据和方法打包到类里，隐藏内部细节，只暴露必要接口。用 public/private/protected 控制访问权限
继承（Inheritance）
子类复用父类的属性和方法，同时可以扩展自己的功能。实现代码复用
多态（Polymorphism）
同一接口不同实现。编译时多态（重载、模板）+ 运行时多态（虚函数）

类的定义

class Person { private: // 私有：类外面不能访问（默认就是private） string name; int age; public: // 公有：类外面可以访问 // 构造函数：创建对象时自动调用 Person() { age = 0; } Person(string n, int a) : name(n), age(a) {} // 初始化列表 // 析构函数：对象销毁时自动调用 ~Person() {} // 成员函数 void setName(string n) { name = n; } string getName() { return name; } void eat(); // 声明 protected: // 保护：自己和子类能访问 string secret; }; // 类外定义成员函数 void Person::eat() { cout << name << "在吃饭" << endl; }

构造函数 & 析构函数

class A { public: A() { cout << "构造" << endl; } ~A() { cout << "析构" << endl; } }; // 构造函数特点： // 1. 与类同名，无返回值 // 2. 创建对象时自动调用 // 3. 可以重载 // 4. 不写的话编译器自动生成默认构造 // 析构函数特点： // 1. ~类名，无返回值，无参数 // 2. 对象销毁时自动调用 // 3. 不能重载（只有一个） // 4. 顺序：先构造的后析构（栈式）

初始化列表

继承与多态

重点难点

继承语法

class Animal { // 父类（基类） protected: string name; public: void eat() { cout << name << "在吃饭" << endl; } }; class Dog : public Animal { // 子类（派生类），公有继承 public: void bark() { cout << "汪汪汪" << endl; } }; // 继承方式影响成员在子类中的访问权限： // public继承： public→public, protected→protected, private→不可访问 // protected继承：public→protected,protected→protected, private→不可访问 // private继承： public→private, protected→private, private→不可访问

继承中的构造析构顺序

// 构造顺序：父类 → 成员对象 → 子类 // 析构顺序：子类 → 成员对象 → 父类（相反） class A { public: A() { cout << "A构造"; } ~A() { cout << "A析构"; } }; class B : public A { A a; // 成员对象 public: B() { cout << "B构造"; } ~B() { cout << "B析构"; } }; // 创建 B 对象输出：A构造 A构造 B构造 // 销毁 B 对象输出：B析构 A析构 A析构

函数重写（Override）

class Animal { public: void speak() { cout << "动物叫" << endl; } }; class Cat : public Animal { public: void speak() { cout << "喵喵喵" << endl; } // 重写父类方法 }; // 注意：重写 vs 重载 // 重载：同一作用域，同名不同参 // 重写：父子类，同名同参同返回（虚函数时才是多态）

虚函数与多态

class Animal { public: virtual void speak() { cout << "动物叫"; } // 虚函数 virtual ~Animal() {} // 虚析构函数（重要！） }; class Dog : public Animal { public: void speak() override { cout << "汪汪汪"; } }; class Cat : public Animal { public: void speak() override { cout << "喵喵喵"; } }; // 多态：父类指针指向子类对象，调用虚函数 Animal *p = new Dog(); p->speak(); // 输出 "汪汪汪"（调用的是 Dog 的 speak） delete p; p = new Cat(); p->speak(); // 输出 "喵喵喵" delete p;
多态的三个条件
1. 有继承关系
2. 子类重写父类的虚函数
3. 父类指针/引用指向子类对象，调用虚函数

多态实现原理：虚函数表（vtable）

// 每个有虚函数的类都有一张虚函数表 // 每个对象都有一个虚函数指针（vptr）指向自己类的虚函数表 // 调用虚函数时，通过 vptr 找到 vtable，再找到真正的函数地址 // 所以有虚函数的对象会多 4/8 字节（vptr 的大小） // 虚函数调用比普通函数慢一点（多了一次查表）
虚析构函数
只要类里有虚函数，析构函数一定要声明为 virtual！
否则用父类指针 delete 子类对象时，只会调用父类析构，子类析构不执行，导致内存泄漏。

纯虚函数 & 抽象类

class Shape { // 抽象类：包含纯虚函数的类 public: virtual double area() = 0; // 纯虚函数 virtual ~Shape() {} }; class Circle : public Shape { double r; public: Circle(double r) : r(r) {} double area() override { return 3.14 * r * r; } }; // 抽象类不能实例化 // Shape s; // 错误！ Shape *p = new Circle(5); // 可以用指针/引用

多重继承 & 菱形继承

// 多重继承：一个子类有多个父类 class A { public: int a; }; class B { public: int b; }; class C : public A, public B { public: int c; }; // 菱形继承问题： // A // / \ // B C // \ / // D // D 继承了两份 A 的成员，有二义性和数据冗余 // 解决：虚继承 class B : virtual public A {}; class C : virtual public A {}; class D : public B, public C {}; // 现在 D 只有一份 A 的成员了

class String { char *str; public: String(const char *s) { str = new char[strlen(s)+1]; strcpy(str, s); } // 默认拷贝构造 = 浅拷贝：只复制指针地址 // 两个对象指向同一块内存，析构时double free // 深拷贝：重新申请内存，复制内容 String(const String &other) { str = new char[strlen(other.str)+1]; strcpy(str, other.str); } // 赋值运算符重载也要深拷贝 String& operator=(const String &other) { if (this != &other) { // 防止自赋值 delete[] str; // 释放旧资源 str = new char[strlen(other.str)+1]; strcpy(str, other.str); } return *this; } ~String() { delete[] str; } };
什么时候需要自己写拷贝构造？
类里有指针成员或动态分配的资源（文件、网络连接等）时，必须自己写深拷贝和赋值运算符重载。这就是三/五法则。

三法则 / 五法则 / 零法则

// 三法则（C++98）： // 如果你需要写析构函数、拷贝构造、赋值运算符中的任意一个， // 那三个几乎都要写。 // 五法则（C++11）： // 加上移动构造和移动赋值，共5个 class A { public: ~A(); // 析构 A(const A&); // 拷贝构造 A& operator=(const A&); // 拷贝赋值 A(A&&); // 移动构造（C++11） A& operator=(A&&); // 移动赋值（C++11） }; // 零法则（最佳实践）： // 尽量不用裸指针，用智能指针/STL容器， // 让编译器自动生成这5个函数，你一个都不用写。

面试高频问题速答

面试专用
问题参考回答
C 和 C++ 的区别？ C是面向过程，C++支持面向对象、泛型编程、STL、异常处理、引用、new/delete、函数重载等。C++是C的超集
面向对象的三大特性？ 封装：隐藏实现细节，只暴露接口（public/private/protected）
继承：子类复用父类属性和方法，实现代码复用
多态：同一接口不同实现，分编译时多态（重载、模板）和运行时多态（虚函数）
多态的实现原理？ 运行时多态通过虚函数表(vtable)实现。每个有虚函数的类有一张虚函数表，每个对象有一个虚指针(vptr)指向自己类的虚函数表。调用虚函数时，通过vptr找到vtable再找到函数地址
构造函数可以是虚函数吗？析构函数呢？ 构造函数不能是虚函数（对象还没完全构造好，vptr还没初始化）。
析构函数建议是虚函数，尤其是有虚函数的类。否则用父类指针delete子类对象时，只会调用父类析构，导致内存泄漏
虚函数和纯虚函数的区别？ 虚函数有实现，子类可以重写也可以不重写。纯虚函数只有声明没有实现（=0），包含纯虚函数的类是抽象类，不能实例化，子类必须实现纯虚函数才能实例化
重载、重写、隐藏的区别？ 重载：同一作用域，函数名相同参数不同
重写（覆盖）：子类重写父类的虚函数，函数名参数返回值都相同
隐藏：子类的函数名和父类一样（不管参数），父类的同名函数被隐藏
指针和引用的区别？ 1. 引用必须初始化，指针可以不
2. 引用不能改指向，指针可以
3. 引用不能为空，指针可以是NULL
4. sizeof引用是变量大小，sizeof指针是4/8字节
5. 引用是变量别名，指针是存地址的变量
malloc/free 和 new/delete 的区别？ malloc是函数，new是操作符；malloc不调用构造，new调用；malloc返回void*，new返回具体类型；malloc失败返回NULL，new抛异常；new可以重载
什么是内存泄漏？怎么检测？ 申请的内存用完不释放就是内存泄漏。检测工具：Linux下valgrind，Windows下Visual Studio的CRT调试库、Intel Inspector等。避免方法：用智能指针、RAII
什么是 RAII？ 资源获取即初始化（Resource Acquisition Is Initialization）。用对象管理资源，构造时获取资源，析构时释放资源。智能指针、lock_guard都是典型应用
深拷贝和浅拷贝的区别？ 浅拷贝：只复制指针的值，两个对象指向同一块内存，析构时double free
深拷贝：重新申请内存并复制内容，各有各的资源，互不影响
类里有指针成员时必须用深拷贝
static 关键字的作用？ C语言中：1. 静态局部变量（延长生命周期）2. 静态全局变量/函数（限制作用域在本文件）
C++中：1. 静态成员变量（所有对象共享）2. 静态成员函数（只能访问静态成员，没有this指针）
const 关键字的作用？ 1. const变量：只读，不能修改
2. const指针：指向const的指针 / const指针
3. const成员函数：不能修改成员变量
4. const引用：只读传参，避免拷贝
vector 的底层原理？ 底层是动态数组，连续内存。容量不够时自动扩容（通常1.5倍或2倍），扩容时要重新分配内存、拷贝元素、释放旧内存。所以push_back均摊时间复杂度是O(1)。可以用reserve预分配减少扩容
map 和 unordered_map 的区别？ map底层是红黑树，有序，查找O(logn)，插入删除O(logn)
unordered_map底层是哈希表，无序，查找平均O(1)，最坏O(n)，消耗更多内存
需要有序用map，追求速度用unordered_map
什么是智能指针？ C++11引入，用RAII管理动态内存，自动释放防止泄漏。
unique_ptr：独占所有权，不能拷贝
shared_ptr：共享所有权，引用计数
weak_ptr：辅助shared_ptr，解决循环引用问题
shared_ptr 的线程安全？ 引用计数是原子操作，是线程安全的。但对象本身的读写不是线程安全的，多线程读写同一个对象需要加锁
什么是循环引用？怎么解决？ 两个对象互相用shared_ptr指向对方，导致引用计数永远不为0，内存泄漏。解决方法：把其中一方改成weak_ptr，weak_ptr不增加引用计数
左值和右值的区别？ 左值：可以取地址、有名字、持久存在（如变量）
右值：不能取地址、没名字、临时的（如字面量、临时对象、std::move后的对象）
C++11引入右值引用(&&)实现移动语义，减少拷贝提高效率
什么是 Lambda？ 匿名函数，可以捕获外部变量。组成：[捕获列表](参数列表) mutable -> 返回类型 {函数体}。捕获方式：=值捕获全部、&引用捕获全部、指定变量捕获
