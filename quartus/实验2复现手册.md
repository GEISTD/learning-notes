# 实验2 复现手册（速查）

## 一句话
用四种写法实现同一个 2 选 1 选择器（SEL=0 输出 A，SEL=1 输出 B），看它们的电路和波形是否一致。

真值表：

| SEL | B | A | L |
|---|---|---|---|
| 0 | x | 0 | 0 |
| 0 | x | 1 | 1 |
| 1 | 0 | x | 0 |
| 1 | 1 | x | 1 |

即 `L = SEL ? B : A`。

## 四个文件
| 文件 | 写法 | module |
|---|---|---|
| `..._exp2_1.v` | 门级：not / and / and / or | mux2to1_ga |
| `..._exp2_2.v` | 三态门：bufif0 / bufif1 | mux2to1_tri |
| `..._exp2_3.v` | 数据流：assign ?: | mux2to1_df |
| `..._exp2_4.v` | 行为级：always + if/else | mux2to1_bh |

## 建工程（每个文件一个工程，重复 4 次）
1. `File > New Project Wizard`
2. 目录 `工程\projN`，工程名 `exp2_N`，**顶层实体 = 对应 module 名**（如 `mux2to1_df`）
3. Empty project
4. Add Files：只加**设计文件**，不要加 `_test.v`
5. Family `Cyclone IV E`，过滤 TQFP / 144 / speed 8，选 `EP4CE6E22C8`
6. Simulation 选 `ModelSim-Altera`，Format `Verilog HDL` → Finish
7. `Ctrl+K` 综合，Messages 里 Error 必须为 0

## 看电路
`Tools > Netlist Viewers > RTL Viewer`（必须先综合成功）

## 仿真（在 仿真\sim_N 目录）
```powershell
vlib work
vlog ..\..\工程\src\W4C4_2025112470_exp2_N.v ..\..\工程\src\W4C4_2025112470_exp2_N_test.v
vsim -c -wlf W4C4_2025112470_exp2_N_test.wlf -do "add wave -r /*; run 495 ns; quit -f" work.W4C4_2025112470_exp2_N_test
```
看到 `test done: coverage 8/8, 0 error(s)` 即成功。

## 引脚
| 信号 | 器件 | PIN |
|---|---|---|
| A | SW10 | PIN_6 |
| B | SW11 | PIN_144 |
| SEL | SW12 | PIN_8 |
| L | LED5 | PIN_53 |

`Assignments > Pin Planner` 填 Location，I/O Standard 选 3.3-V LVTTL。

双功能引脚：`Assignments > Device > Device and Pin Options > Dual-Purpose Pins`，
把能改的都改成 `Use as regular I/O`（至少 ASDO/DATA1、FLASH_nCE/nCSO 两项），否则报
`Can't place multiple pins assigned to pin location Pin_6`。

## 编译下载
- `Ctrl+L` 全编译 → 生成 `.sof`
- `Tools > Programmer` → Hardware Setup 选 `USB-Blaster [USB-0]` → Mode `JTAG`
  → Add File 选 `.sof` → Start → `Configuration succeeded`
- `.sof` 掉电即失，重新上电要重烧

## 上板现象
拨 SW10/11/12，LED5 应等于"SEL 选中的那一路"。
若开关是低有效（拨到 ON 读到 0），现象相反，按实际记录即可。

## 常见报错
| 报错 | 原因 | 解决 |
|---|---|---|
| Top-level entity not found | 顶层实体名 ≠ module 名 | 改成一致 |
| Can't place multiple pins ... Pin_6 | 双功能引脚 | Dual-Purpose Pins 设为 regular I/O |
| 仿真全 X | 选了设计模块当顶层 | 选 `*_test` |
| 波形没变化 | 没重新编译 | 先 vlog 再 vsim |
| Programmer 里 Start 灰 | 没加 .sof | Add File |
