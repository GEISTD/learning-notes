# Quartus 从零开始 · 手把手教程（每一步点哪里都写明）

> 目标：自己独立建一个工程、写一个文件、编译、仿真，做出第一份作品（4 位加法器）。
> 阅读方式：每个大阶段结尾都有「✔ 此时你应该看到……」，看到它说明你走对了，没看到就停下来复查本节。

---

## 阶段 0：前提检查（先弄清楚你手上有什么）

打开开始菜单，找 **Quartus Prime** 主程序（图标是一个蓝色三角）。

- 找得到 → 继续阶段 1；
- 只找得到 "Quartus Prime Programmer"（烧录工具）→ 说明主程序没装，暂不能做阶段 1，直接跳到**阶段 5（无 Quartus 路线）**；
- 什么都找不到 → 先装完整版 `QuartusSetup-24.1std.0.1077-windows.exe` 和器件包 `cyclone-24.1std.0.1077.qdz`。

先做一个文件夹：打开资源管理器，建 `D:\fpga_work`（**纯英文、无空格**，以后所有工程都放这里面）。

---

## 阶段 1：新建工程（跟着向导点，一共 9 步）

1. 打开 Quartus Prime 主程序；
2. 菜单栏点 **File → New Project Wizard...**；
3. 第 1 页只是介绍，直接点 **Next**；
4. **选路径和起名字**（第 2 页）：
   - 第 1 行（Working directory）：填 `D:\fpga_work\full_adder`；
   - 第 2 行（Name of project）：填 `full_adder_4bit`；
   - 第 3 行（Top-level entity）会自动跟着变成 `full_adder_4bit`，不用管；
   - 点 **Next**；
5. 第 3 页（Add Files）——**把设计文件加进工程**：
   - 点文件名列表右边的 **...** 按钮，进入 `full_adder` 文件夹（我们准备好的），选中 `rtl` 里的 `full_adder.v` 和 `full_adder_4bit.v` 两个文件，点 **打开**；
   - 回到向导后点 **Add**，两个文件出现在列表里；
   - 点 **Next**；
   - （`sim\tb_full_adder.v` 先别加，它到阶段 4 仿真时再加；加了也不影响。）
6. 第 4 页（Device）——**选芯片**：
   - Family 下拉框选 `Cyclone IV E`；
   - 右边 Name filter 输入框里输入 `EP4CE6E22C8`；
   - 点击下方列表里出现的那一行将它选中；
   - 点 **Next**；
7. 第 5 页（EDA Tool Settings）：
   - Simulation 下拉框选 `ModelSim`（有些版本叫 ModelSim-Altera）；
   - Format 保持 `Verilog HDL`；
   - 点 **Next**；
8. 最后一页（Summary）确认各项无误，点 **Finish**；
9. 把仿真文件也加进来备用：菜单 **Project → Add/Remove Files in Project...** → 点 **...** → 选 `sim\tb_full_adder.v` → 点 **Add** → **OK**。

> ✔ 此时你应该看到：左侧 Project Navigator 面板里有一个分层文件树，能展开看到 `full_adder.v` 和 `full_adder_4bit.v` 两个文件图标，顶部显示器件 `EP4CE6E22C8`。

## 阶段 2：自己动手写第一个文件（.v 文件）

1. 菜单 **File → New...** → 选 **Verilog HDL File** → **OK**，出现一个空白编辑器标签页；
2. 把下面的代码**照着打一遍**（打比复制记得牢，注释可以不打）：

```verilog
// 1 位全加器：门级建模，和数电课本的电路图一一对应
module full_adder(
    input  a, b, cin,     // 两个加数位 + 低位来的进位
    output sum, cout      // 本位的和 + 向高位的进位
);
    wire s, c1, c2;       // 中间节点：s、c1、c2

    xor  (s,   a, b);     // s   = a ⊕ b
    xor  (sum, s, cin);   // sum = s ⊕ cin
    and  (c1,  a, b);     // c1  = a · b
    and  (c2,  s, cin);   // c2  = s · cin
    or   (cout, c1, c2);  // cout = c1 + c2
endmodule
```

3. 菜单 **File → Save As...** → 存到 `D:\fpga_work\full_adder\rtl\`，文件名 **必须** 是 `full_adder.v`（和 `module full_adder` 同名，Quartus 强制要求）；
4. 同样的方法再建一个文件 `full_adder_4bit.v`，内容如下：

```verilog
// 4 位行波进位加法器：4 个 1 位全加器级联（对应 74LS283）
module full_adder_4bit(
    input  [3:0] a, b,    // 两个 4 位加数
    input        cin,     // 最低位的进位输入
    output [3:0] sum,     // 4 位结果
    output       cout     // 最高位的进位输出（溢出标志）
);
    wire c1, c2, c3;      // 各级之间的进位连接线

    full_adder fa0 (.a(a[0]), .b(b[0]), .cin(cin), .sum(sum[0]), .cout(c1));
    full_adder fa1 (.a(a[1]), .b(b[1]), .cin(c1),  .sum(sum[1]), .cout(c2));
    full_adder fa2 (.a(a[2]), .b(b[2]), .cin(c2),  .sum(sum[2]), .cout(c3));
    full_adder fa3 (.a(a[3]), .b(b[3]), .cin(c3),  .sum(sum[3]), .cout(cout));

endmodule
```

5. 如果之前向导里已经 Add 过这两个文件——**建议把向导加进去的文件从工程里移除，改用你自己打的两个**（这样才是真正"从零"）：菜单 **Project → Add/Remove Files in Project...** → 选中旧的 → **Remove** → **...** 加上你自己存的 → **Add** → **OK**。

> ✔ 此时你应该看到：编辑区没有红色波浪线；左侧文件树里两个文件图标都在。这 4 行 `full_adder fa0(...)` 就是"模块例化"——像芯片一样把 4 个全加器插在电路板上。

## 阶段 3：编译（让软件把你的文字变成电路）

1. 点工具栏上的**▶ 三角图标**（悬停提示 Start Compilation），或菜单 **Processing → Start Compilation**；
2. 左下角 Task 面板会依次跑 4 个阶段：Analysis & Synthesis → Fitter → Assembler → Timing Analysis，每个前面依次出现小绿勾；
3. 全部跑完会弹出编译报告。

> ✔ 此时你应该看到：编译结束提示 "Quartus Prime Full Compilation was successful"；报告 Flow Summary 里 Total logic elements 大约是 4 个（不是 0 就说明真生成电路了）。

4. **看一眼生成的电路图（实验报告素材）**：菜单 **Tools → Netlist Viewers → RTL Viewer**。

> ✔ 此时你应该看到：一个窗口里画着 4 个 `full_adder` 方块级联的框图，双击任意一个方块，能看到里面 XOR/AND/OR 门——这就是你写的代码变成的电路。

---

## 阶段 4：仿真（在电脑上验证你的电路对不对）

1. **把测试文件告诉仿真工具**：菜单 **Assignments → Settings...** → 左边树里选 **EDA Tool Settings → Simulation**；
2. 在 **NativeLink settings** 区域勾选 **Compile test bench**；
3. 点旁边的 **Test Benches...** 按钮 → 点 **New...**：
   - Test bench name：`tb_full_adder`；
   - Top level module in test bench：`tb_full_adder`；
   - Design instance name in test bench：`uut`（保持默认也行）；
   - 下方 File name 栏点 **...** → 选 `sim\tb_full_adder.v` → 点 **Add**；
   - 一路点 **OK** 关闭所有窗口；
4. 菜单 **Tools → Run Simulation Tool → RTL Simulation**；
   - 这时 Quartus 会自动编译并打开 ModelSim，仿真开始跑；
5. 如果 ModelSim 打开了但**波形窗口是空的**，在 ModelSim 底部命令行（Transcript 输入框）依次敲这三行，每行回车：

```
vsim work.tb_full_adder
add wave *
run -all
```

> ✔ 此时你应该看到：**下方 Transcript 面板**里依次打印 8 行"通过 ..."、一行"1位全加器测试结束：8 项中 0 项错误"，接着 4 行"通过 3 + 5 = 8 ..."、一行"4位加法器测试结束：4 项中 0 项错误"。**上方 Wave 窗口**有 a、b、cin、sum、cout 的波形在跳。把这两个画面截图，就是实验报告的核心证据。

## 阶段 5：没有 Quartus 时的路线（今天就能跑）

注册并打开 [EDA Playground](https://www.edaplayground.com)：

1. 左上角 **Testbench + Design** 保持默认；Language 选 `Verilog`；Simulator 选 `Icarus Verilog 0.10.0`；
2. 左边大框粘贴 `rtl\full_adder.v` 和 `rtl\full_adder_4bit.v` 的内容（全选复制进去）；
3. 点左边框下方的 **+ testbench**，把 `sim\tb_full_adder.v` 全部内容粘贴到新出现的框里；
4. 点左上角 **Run** 按钮。

> ✔ 此时你应该看到：下方日志出现和阶段 4 相同的"8 项中 0 项错误、4 项中 0 项错误"。

---

## 阶段 6：参考答案怎么用

文件夹里的 `full_adder_4bit.qpf` 是"参考答案工程"——你在哪一步卡住了，就双击打开它对比设置是否正确。**但作业流程请按阶段 1~4 自己走一遍**，走出来的东西才是你自己的。

## 常见卡壳速查

| 现象 | 原因 / 解法 |
|---|---|
| 编译报错 Page not found 之类 | 工程路径含中文或空格，搬到 `D:\fpga_work\` |
| 文件名改了但编译不通过 | .v 文件名必须和 `module` 名完全一致 |
| 仿真按钮是灰色 | 没做阶段 4 第 1~3 步的 Test Bench 关联 |
| ModelSim 提示找不到 full_adder | 编译顺序：先编译全部 rtl 和 tb，再 vsim；用 do 脚本最省事 |
| 改了代码波形没变 | 必须重新 Start Compilation / 重新 Run Simulation |
| RTL Viewer 打不开 | 必须先成功编译过一次 |

> 从下次起，每个新实验走同一套流程：**建工程 → 加文件 → 编译 → 波形 → 上板**，熟练后 20 分钟内就能走完一遍，这就是数电实验课的基本功。
